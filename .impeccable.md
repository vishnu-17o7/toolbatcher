## Design Context

### Users
- Primary users are developers, DevOps engineers, and technical leads who need to bootstrap project environments quickly across Linux, macOS, and Windows.
- Typical context is time-sensitive setup during project kickoff, onboarding, CI/local parity checks, and machine migration.
- Core job to be done: select the right toolchain and versions, generate a trusted install command, and execute with confidence.

### Brand Personality
- 3-word personality: precise, confident, refined.
- Emotional goal: reduce setup anxiety and create a sense of control, speed, and trustworthiness.
- Voice and tone: direct and technical, but never cold or cluttered.

### Aesthetic Direction
- Direction: editorial / premium / sharp, dark-first.
- Visual tone: high-contrast typography, restrained but rich color accents, asymmetric composition, intentional whitespace rhythm.
- Avoid: generic "neon dev dashboard" styles, gradient-text gimmicks, repetitive card grids, and default UI-library look.

### Design Principles
1. Clarity over decoration: every visual treatment must improve comprehension or hierarchy.
2. Trust through precision: use structured spacing, strong type hierarchy, and explicit interaction states.
3. One memorable motif: keep a distinctive editorial signature across hero, controls, and section transitions.
4. Fast-feeling interactions: immediate feedback, clear loading/error states, and reduced-motion-safe animations.
5. Functional aesthetics: styling must preserve accessibility, responsiveness, and production reliability.
